# AssettoCars

Лендинг-каталог модов для Assetto Corsa: тёмная тема, красный акцент,
фильтр по дисциплине/приводу/марке/мощности с явным подтверждением
("Применить фильтры"), пагинация, детальная карточка мода, вход через
Google/GitHub и полноценная админ-панель — всё без выделенного бэкенда,
на GitHub Pages + GitHub API.

**Сайт:** https://matevosyangevorg.github.io/assettocars/
**Админ-панель:** https://matevosyangevorg.github.io/assettocars/admin.html (приватная, см. ниже)

## Версия

**v1.1** — текущая стабильная версия. См. [CHANGELOG.md](./CHANGELOG.md) за полной историей изменений.

## Структура
- `index.html` — публичный сайт. Загружает каталог из `data/cars.json` (через raw.githubusercontent.com) при каждом открытии.
- `data/cars.json` — данные о модах: единственный источник правды для сайта и админки.
- `data/images/`, `data/mods/` — загруженные через админку фото и архивы модов.
- `admin.html` — приватная панель управления каталогом.

## Возможности
- Каталог с фильтрами (дисциплина, привод, марка, мощность) и пагинацией; новые моды сразу показываются первыми
- Детальная карточка мода: характеристики, фото, скачивание
- Вход через **Google** и **GitHub** (Firebase Auth) — скачивание мода доступно только авторизованным
- Админ-панель: добавление/редактирование/удаление модов, загрузка фото и архивов мода прямо в репозиторий, корзина с восстановлением
- Адаптивная вёрстка под телефоны, планшеты, ноутбуки и широкие мониторы

## Запуск
Сборка не нужна — всё на чистом HTML/CSS/JS. Но `index.html` загружает
данные через `fetch()`, поэтому открывать нужно либо через **GitHub Pages**,
либо через локальный сервер:

```
python3 -m http.server 8000
```

## Админ-панель (`admin.html`)
Приватная страница для добавления/редактирования/удаления модов, загрузки
фото и архивов без ручного редактирования кода. Все изменения публикуются
напрямую в этот репозиторий через GitHub Contents API — сайт подхватывает
их при следующей загрузке (обычно почти сразу, возможна задержка в
несколько минут из-за CDN на стороне GitHub).

**Как войти:** пароль-заглушка (задан в `admin.html`, константа
`ADMIN_PASSPHRASE`) и **GitHub Personal Access Token** со scope `repo`
([github.com/settings/tokens](https://github.com/settings/tokens)).
Токен нигде не сохраняется на диске — только в памяти вкладки на время сессии.

**Важно:** пароль на входе — не серверная авторизация (статический сайт
физически не может её обеспечить), а просто барьер от случайных
посетителей. Реальная защита — GitHub-токен с правом записи, который есть
только у владельца репозитория. Не публикуй ссылку на `admin.html` и не
делись токеном.

## Авторизация на сайте (Firebase)
Вход через Google/GitHub настроен через Firebase Authentication
(`assettocars-45c70`). Требуется, чтобы в Firebase Console были включены
оба провайдера и домен `matevosyangevorg.github.io` был добавлен в
Authorized domains.
