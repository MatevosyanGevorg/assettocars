# AssettoCars

Лендинг-каталог модов для Assetto Corsa: тёмная тема, красный акцент,
фильтр по дисциплине/приводу/марке/мощности с явным подтверждением
("Применить фильтры"), пагинация каталога, детальная карточка мода
и анимированный заголовок в hero-блоке.

## Структура
- `index.html` — публичный сайт. Загружает каталог из `data/cars.json` при открытии.
- `data/cars.json` — данные о модах (единственный источник правды для сайта и админки).
- `admin.html` — приватная админ-панель для управления каталогом (см. ниже).

## Запуск
Сборка не нужна — всё на чистом HTML/CSS/JS. Но `index.html` подгружает
`data/cars.json` через `fetch()`, а браузеры блокируют такие запросы при
открытии файла напрямую (`file://`). Поэтому смотреть сайт нужно либо через
**GitHub Pages**, либо через локальный сервер, например:

```
python3 -m http.server 8000
```

## Админ-панель (`admin.html`)
Приватная страница для добавления/редактирования/удаления модов без
переписывания кода вручную. Изменения публикуются напрямую в
`data/cars.json` в этом репозитории через GitHub Contents API — сайт
подхватывает их при следующей загрузке.

**Как войти:** нужен пароль-заглушка (задан в `admin.html`, ищи константу
`ADMIN_PASSPHRASE`) и **GitHub Personal Access Token** со scope `repo`
(создаётся на [github.com/settings/tokens](https://github.com/settings/tokens)).
Токен нигде не сохраняется на диске — только в памяти вкладки на время сессии.

**Важно:** пароль на входе — это не серверная авторизация (статический сайт
физически не может её обеспечить), а просто барьер от случайных посетителей.
Реальная защита — GitHub-токен с правом записи, который есть только у
владельца репозитория. Не публикуй ссылку на `admin.html` и не делись
токеном.
