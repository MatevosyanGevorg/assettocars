# AssettoCars

Лендинг-каталог модов для Assetto Corsa: тёмная тема, красный акцент,
фильтр по дисциплине/приводу/марке/мощности с явным подтверждением
("Применить фильтры"), пагинация каталога, детальная карточка мода
и анимированный заголовок в hero-блоке.

## Запуск
Просто открой `index.html` в браузере — сборка не требуется,
всё на чистом HTML/CSS/JS в одном файле.
