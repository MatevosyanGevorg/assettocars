# Changelog

## v1.1 — текущая версия

**Админ-панель и данные**
- Каталог машин вынесен из кода в отдельный `data/cars.json` — общий источник данных для сайта и админки
- Новая приватная админ-панель (`admin.html`): добавление, редактирование, удаление модов
- Загрузка фото мода и архива мода прямо из админки — файлы кладутся в репозиторий через GitHub Contents API, без стороннего хранилища
- Корзина: удалённые моды не исчезают безвозвратно — их можно восстановить или удалить навсегда
- Публикация из админки стала надёжнее: автообновление sha файла и повтор при конфликте записи, более заметные сообщения об ошибках
- Кастомные модальные подтверждения вместо стандартных браузерных `confirm()`

**Вход и доступ**
- Вход через **Google** и **GitHub** (Firebase Authentication)
- Скачивание мода требует авторизации; после входа скачивание запускается автоматически
- На узких экранах блок аккаунта переехал в мобильное меню, чтобы не мешать шапке

**Каталог и карточки**
- Новые моды теперь показываются первыми (сортировка по дате добавления)
- Загруженные фото модов действительно отображаются на карточках, странице мода и в hero-галерее (раньше показывалась только схематичная иконка)
- Кнопка «Скачать мод» ведёт на реально загруженный файл или внешнюю ссылку
- Расширен диапазон фильтра по мощности (0–2000 л.с. вместо 150–1200) — раньше мод с низкой мощностью мог тихо пропадать из каталога

**Стабильность**
- Исправлен баг с прыжком страницы при переключении пагинации на короткой последней странице
- Обход CDN-кэша GitHub Pages при загрузке каталога — публикация из админки отражается на сайте практически сразу
- Устранён баг со scroll-anchoring при пересборке сетки карточек во время фильтрации

**Адаптивная вёрстка**
- Полный проход по брейкпоинтам на index.html и admin.html
- Мобильное меню (гамбургер) вместо пропадающей без замены навигации
- Исправлена «мёртвая зона» 960–1120px, где одновременно ломались шапка и hero-галерея
- Hero-галерея на планшетах и телефонах — горизонтальная свайп-лента вместо перекрывающихся карточек
- Админ-панель: таблица со скроллом, адаптивные формы и тулбар

## v1.0 — первая рабочая версия

- Лендинг-каталог модов Assetto Corsa: тёмная тема, красный акцент, анимированный hero-заголовок
- Фильтры по дисциплине, приводу, марке и мощности с явным подтверждением («Применить фильтры»)
- Пагинация каталога, детальная карточка мода со спек-барами
- Публикация на GitHub Pages
